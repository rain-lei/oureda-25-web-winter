# Wordle 游戏

这是一个基于 Web 的 Wordle 游戏，玩家需要在限定次数内猜出正确的5字母单词。

## 项目简介

Wordle 是一款流行的单词猜测游戏。玩家需要根据每次猜测的结果（颜色反馈）逐步缩小范围，最终猜出隐藏的单词。游戏中每个字母会被标记为以下三种颜色之一：

- 🟩 绿色（正确位置）：字母正确且位置正确
- 🟨 黄色（存在但位置错误）：字母存在于答案中但位置错误
- ⬜ 灰色（不存在）：字母不存在于答案中

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)

## 功能特性

- 6次机会猜测5字母单词
- 实时反馈字母的匹配情况（绿色、黄色、灰色）
- 屏幕键盘支持
- 物理键盘支持（字母键、回车、退格）
- 随机单词生成（来自词汇库）
- 重新开始游戏
- 显示答案功能

## 游戏玩法

1. 使用屏幕键盘或物理键盘输入5个字母的单词
2. 按下"Enter"键提交猜测
3. 根据字母的反馈颜色调整下一次猜测
4. 在6次尝试内猜出正确单词即可获胜
5. 如果6次都未猜中，则游戏失败

## 代码结构

### HTML 结构
- 游戏网格（6行×5列）用于显示猜测结果
- 屏幕键盘（QWERTY布局）
- 控制按钮（刷新、显示答案）

### CSS 样式
- 网格布局使用 Flexbox
- 字母单元格的颜色反馈样式
- 键盘按钮的颜色反馈样式
- 响应式设计适配不同屏幕尺寸

### JavaScript 逻辑
- 全局状态管理（答案、当前猜测、尝试次数等）
- 事件监听器（键盘输入、点击屏幕键盘）
- 颜色匹配算法
- 词汇验证（检查输入的单词是否有效）
- 游戏状态管理（未完成、已解决、失败）

## 词汇库

游戏使用 `words.json` 文件中的词汇库，包含超过1000个常用的5字母英文单词。游戏启动时会从词汇库中随机选择一个单词作为答案。

## 主要函数

- `start()` - 程序入口函数
- `render()` - 渲染游戏界面
- `initialize()` - 初始化游戏状态
- `generateRandomAnswer()` - 随机生成答案
- `isValidWord()` - 验证单词是否合法
- `handleAnswer()` - 处理用户猜测
- `calculateColorSequence()` - 计算颜色匹配序列

## 扩展功能

- 点击"答案显示"按钮可以查看正确答案
- 点击"刷新"按钮可以重新开始游戏
